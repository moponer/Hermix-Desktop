# 界面设计 · 一轴两面

> 2026-09-28 · 取代 `UI_REDESIGN_PAPER_INK_2026-09-28.md`（那份是诊断，这份是设计）
> 主题：宣纸（light）/ 夜墨（dark），仅此两套

---

## 0. 设计立场

现在几乎所有 agent 界面都在做同一件事：把 agent 的每一步都摊开给你看——思考卡、
工具卡、命令输出卡、待办卡、总结卡，用一串等宽小盒子制造"很忙碌"的观感。
结果就是**你必须自己从噪音里捞结论**。

这套设计反过来做一句话：

> **结果优先，过程按需。默认只给结论和一行状态，过程永远可召出但默认收起。**

由此推出三个结构决策：

| 决策 | 现状 | 新设计 |
|---|---|---|
| 屏幕是给谁的 | 摊开所有过程 | 默认只留「正在发生」和「等你决定」 |
| 注意力怎么分 | 所有轮次等权平铺 | 三态分级：进行中 / 待你 / 已完成（自动收缩） |
| 元信息放哪 | 挤在输入框里（模型/工作区/权限 chip） | 上移到顶栏，输入框回归"只打字" |

## 1. 总体布局：从「三栏常驻」到「一轴两面」

### 1.1 现状的硬伤

`.app-body` 是三列 grid，左 200px + 主区 + 右栏 **默认 640px**（`App.tsx` 的
`right.width`）。在 1280px 宽的窗口上，对话区只剩 440px；在 1140px 时右栏被
自动关闭。**也就是说：默认状态下，聊天区被一个大多数时候没在用的面板吃掉一半。**

### 1.2 新布局

```
┌──────────────────────────────────────────────────────────────┐
│ ● Hermes    把认证模块拆出来                        夜墨 ▾  ⋯ │ 48px 上下文栏
├────────────┬─────────────────────────────────────────────────┤
│ ⌕ 搜索     │                                                 │
│            │                                                 │
│ 今天        │        主轴：对话（满宽 · 纸面）                 │
│  ◉ 重构认证 │                                                 │
│    修复构建 │        68ch 排版 · 1.75 行高 · 无边框            │
│ 昨天        │                                                 │
│    补测试   │                                                 │
│            │                                                 │
│ 归档  全部  │  ┌───────────────────────────────────────┐     │
│            │  │ 说点什么…                          ⏎   │     │ ← 输入（纯打字）
│ ⚙ 视图     │  └───────────────────────────────────────┘     │
└────────────┴─────────────────────────────────────────────────┘
                                            ● ← 悬浮在场球（可拖）
```

**左面 = 任务箱**（会话流，不再塞页面导航）
**主轴 = 内容**（对话 / 页面，纸面）
**右面 = 按需浮层**（默认不存在）

### 1.3 顶栏升级为「上下文栏」

现状顶栏 40px 只放品牌和窗口按钮，聊天标题在 ChatView 内部，元信息在输入框里——
**信息散在三处**。新设计把"我是谁 / 在哪 / 用什么 / 在跑什么"收进一条 48px 细线：

```
┌──────────────────────────────────────────────────────────────────┐
│ ●  Hermes │ 把认证模块拆出来 ⌄ │ gpt-5  ·  ~/work/api  ·  沙箱  │ ●运行中 ⋯ │
└──────────────────────────────────────────────────────────────────┘
   ↑品牌      ↑会话标题(双击内联编辑)   ↑模型·工作区·权限(12px弱化)  ↑状态点
```

效果：主轴从标题到输入框**全是内容**，一寸都不浪费。

## 2. 对话区：注意力三态（核心设计）

这是整套设计里最值钱的部分。

### 2.1 一轮的三种状态

```
① 进行中 ACTIVE              ② 待你 BLOCKED              ③ 已完成 DONE
┌──────────────────────┐      ┏━━━━━━━━━━━━━━━━━━━━━━┓       ┌────────────────────┐
│ ● 思考中 3.2s         │      ┃ 需要你的决定          ┃       │ ▸ 3 个工具 · 12 行  │
│ ● read_file main.rs   │      ┃ 写入 2 个文件到 src/   ┃       │   12:04        ⌄   │
│ ● terminal npm test   │      ┃      [取消]  [允许]   ┃       └────────────────────┘
│ ────────────────────  │      ┗━━━━━━━━━━━━━━━━━━━━━━┛        （点击展开全文）
│ 正文从这里流出……      │        朱砂左边条 + 唯一饱和色          正文默认收进这一行
└──────────────────────┘
```

| 状态 | 判定 | 呈现 |
|---|---|---|
| 进行中 | 有流 / 有工具 / 有审批 | 时间轴 + 正在流的正文，全部可见 |
| 待你 | 有审批挂起 | **唯一使用朱砂的地方**：2px 左边条 + 动词按钮对 |
| 已完成 | 轮次结束 | **自动收缩成一行**；`⌄` 点开，且"展开过就不再自动收缩" |

### 2.2 自动收缩规则（防噪音的核心）

一轮结束后 2 秒，如果它**不是当前最后可见的一轮**（即用户已经往下看了），
正文自动折叠为一行摘要：工具数 / 行数 / 耗时 / 时间。

> 结果：屏幕永远只有 1-2 屏内容，而不是无限长的一条瀑布。
> 历史内容**没有丢**——点开即可，Ctrl+F 也能搜到（文本仍在 DOM）。

### 2.3 向上滚动的"雾化"

用户往上翻阅历史时，越靠上的轮次越安静：

```
滚动位置 ↑   opacity 100% → 55%，加 blur(0.2px)
```

只改 opacity/blur，不动布局、不触发重排、不抖动。滚回底部自动恢复。
**效果**：不用任何"当前消息"高亮框，眼睛自己就知道焦点在哪。

### 2.4 一轮之内的结构：日志在左，信在右

```
│ ● 思考中 3.2s
│ ● read_file   src/auth/session.rs    1.2k 行
│ ● terminal    npm test               ✓ 24 passed
│ ● todo        2/3 完成
│ ┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈  ← 轮次分隔（两端渐隐）
│   正文从这条线下方流出。与纸面同底色、无气泡、无边框、
│   无卡片语言，靠 68ch 行宽和段落节奏读。
```

工具行**永不出现卡片边框**。整列靠一条 1px 竖线（rail）串起来，
左侧 6px 状态点：成功=空心、运行=呼吸、失败=实心。

### 2.5 正文排版（抄墨水屏的六条）

| 规则 | 值 | 为什么 |
|---|---|---|
| 行宽 | `max-width: 68ch`（中文约 34 字） | 更长的行眼睛回扫时会串行 |
| 行高 | `1.75` | 密了累，宽了散 |
| 层级 | **小标题 + 大间距**（14px/600，margin-top 1.6em） | 靠字号做层级最像"网页"不像"书" |
| 引用 | 2px 竖线，无底色块 | 灰底块是 UI 语言，不是阅读语言 |
| 行内代码 | 只换字族，不加底色 | 底色块会把段落切碎 |
| 链接 | 保持墨色 + 朱砂下划线 | 链接换色会打断阅读节奏 |

中文专属：`text-wrap: pretty`、`line-break: strict`、数字用 `tabular-nums`。

### 2.6 用户消息

去掉边框，改 `--color-bg-card`（比纸面亮 = 抬起）+ 0.5px 视觉发丝边。
保留现状"只削左下角"的非对称圆角——这一点现状是对的。

## 3. 输入区：从「控制台」变回「输入框」

现状 Composer 顶部有模型/工作区/权限三个 chip，底部一排工具按钮。
问题不是不好看，是**它们 99% 时间是不变的常量，却占着黄金位置**。

```
┌──────────────────────────────────────────────────────┐
│ 说点什么…                                             │
│                                                      │
├──────────────────────────────────────────────────────┤
│ ＋                                          ⏎ 发送   │
└──────────────────────────────────────────────────────┘
   ↑ 唤起斜杠指令面板      ↑ 唯一实心按钮（朱砂）
```

模型 / 工作区 / 权限 / 沙箱模式**全部上移到顶栏**（§1.3），输入区只留输入。

**斜杠命令面板**（`/` 唤起，也可点 ＋）：打字选中，不用来回点菜单。

```
/模型      gpt-5 · claude · 本地 ollama …
/工作区    ~/work/api · ~/work/web …
/权限      只读 · 标准 · 完全访问
/工具      禁用 write_file / 联网
/子代理    并行 3 个：审查 / 测试 / 文档
/预览      把最后一段渲染成图表
```

## 4. 左面：任务箱（侧栏重设计）

**问题**：现在侧栏把「会话」和「页面导航」混在同一层。会话是任务，页面是工具，
两种东西挤在一个列表里，视觉上无法区分，且 5 个低频页面长期占着位置。

```
┌──────────────┐
│ ⌕ 搜索会话…   │  ← Ctrl+K 全局搜索
├──────────────┤
│ 今天          │  ← 11px / 字重 600 / 字距 0.04em / ink-3
│  ◉ 重构认证模块│  ← 正在跑：朱砂 6px 呼吸点
│    修复构建   │
│ 昨天          │
│    补测试用例 │
├──────────────┤
│ 归档   全部   │
├──────────────┤
│ ⚙ 视图       │  ← 专家/自动化/分析/应用/工作台 收进这里
└──────────────┘
```

- 5 个页面从常驻导航降级为「视图菜单」+ `Ctrl+K` 命令面板入口。
- 会话按时间分组（今天/昨天/更早），替代现在的平铺。
- 底部的用户菜单、设置、主题收纳在此。

## 5. 右面：按需浮层（替掉常驻 640px 右栏）

产物栏/电脑栏默认**不存在**。改为：

**触发**：agent 产出文件时，右下角浮出一条 32px 的细条：
```
┌────────────────────────────────┐
│ 生成 3 个文件 · 查看      ⌄ ✕ │
└────────────────────────────────┘
```
点击 → 从右滑入浮层面板（`clamp(380px, 34vw, 560px)`，overlay 底 + 阴影，
**无遮罩**，主区仍可交互、可滚动）。

**文件预览**同样从"全屏 modal + 模糊遮罩"改为"同一套右侧浮层"——
从"打断"变成"旁看"，是工作流的质变。

## 6. 工作台：悬浮在场球

用户提出的方向成立，并再推一步：**不只是悬浮对话窗，是"智能体在场指示器"**。

现状工作台是"左画布 + 右 460px 固定栏"（`workbench.css:109`），画布被永久切掉
三分之一。改为悬浮后画布拿回 100% 宽度，而且**球可以跨页面常驻**——
你在设置页改配置时也能看到"agent 在想 / 在等你批准"。
这是当前所有 agent 产品的共同盲区：切页即失去对 agent 的感知。

**收起态**（48px 圆，可拖拽，位置按视口比例记忆）

| 状态 | 环 |
|---|---|
| 空闲 | 无环 |
| 思考 | 缓慢旋转的虚线弧（8s/圈，不刺眼） |
| 执行工具 | 不确定态脉冲（呼吸 0.3↔0.8） |
| **待审批** | 芥黄 + **只呼吸一次**（1.2s）后转常亮——一次性，不骚扰 |
| 刚完成 | 对勾划过一次（300ms） |
| 有新消息 | 右上角 8px 朱砂点 |

**展开态**：`clamp(360px,30vw,480px) × clamp(320px,60vh,640px)`，
从球的实际坐标 180ms 缩放展开（`transform-origin` 按球在球的哪一侧算），
顶栏可拖动、右下角可缩放、Esc 收起、离开工作台自动收起（保留位置）。

## 7. 组件级细则

| 组件 | 现状 | 新设计 |
|---|---|---|
| 工具行 | 折叠卡片 + rail | 一行：状态点 + mono 工具名 + 参数 + 结果摘要；hover 出 `⌄`；**无边框** |
| 命令输出 | 深色终端面板 | 默认只给最后 3 行，展开才是终端；hover 出复制/全屏 |
| 审批卡 | 玻璃卡片 | 2px 朱砂左边条 + 标题「需要你的决定」+ 动词按钮（右=实心） |
| 待办 | 卡片 | 左侧 2px 竖条 + 28px 行；完成态用**删除线 + ink-4**，不用绿色对勾块 |
| 子代理 | ? | 折叠成时间轴一行 `子代理 · 代码审查 · 完成` |
| 轮次总结 | 大卡片 | 一条渐隐分隔线 + 一行 chip `已压缩 12 条历史 · 查看` |
| Toast | 顶部居中卡片 | 保留（它是对的），但改为 `--color-bg-elevated` + 更轻的边 |
| 焦点环 | accent 2px outline | 保留，改为 1.5px + 2px offset，减少"重"感 |

## 8. 配色（已实施）

两套主题，深度语法完全同构。

| 令牌层 | 宣纸（light） | 夜墨（dark） |
|---|---|---|
| 案（最外层/侧栏/顶栏） | `#f0eee7` / `#edeae2` | `#0f1115` / `#1a1d23` |
| 纸（对话区） | `#f7f5f0` | `#121419` |
| 面（卡片，恒比纸亮 = 抬起） | `#fcfbf8` | `#181b21` |
| 浮（弹层/菜单/球） | `#ffffff` | `#232833` |
| 墨（朱砂） | `#be4a32` | `#e06a4c` |
| 正文 | `#2b2a27` | `#e9eaee` |

三条与旧版不同的关键决定：

1. **卡片恒比背景亮**（旧版 `--color-bg-card` 与 `--color-bg-primary` 同为
   `#faf9f5`，卡片根本没"抬"起来，层次只能靠到处画边框 → 满屏盒子感）。
2. **正文对比降一档**（约 11.5:1 而非 21:1）——墨水屏久看不累的秘密。
3. **暗色推翻"中性轴必须 R=G=B"铁律**：允许色相、饱和度上限 4%。
   纯中性灰是暗色"水泥感"的直接来源。

语义四色彼此拉开 ≥30° 色相且全部避开朱砂橙区：
松绿 `#2e7a54` / 芥黄 `#96750f` / 绛红 `#a32b54` / 靛灰 `#5b6b7a`。

## 9. 与竞品的六个差异点

1. **轮次自动收缩**——别人是无限长瀑布，这里屏幕恒定 1-2 屏。
2. **滚动雾化焦点**——不靠高亮框，靠不透明度自然指路。
3. **元信息上移**——输入框只负责打字，别家把模型/权限塞在输入区。
4. **页面降级到命令面板**——导航只留"任务"，别家把页面和会话混在一列。
5. **右栏按需浮层**——默认两栏，别家默认三栏且吃掉一半宽度。
6. **跨页在场球**——切到任何页面都知道 agent 在干什么。
