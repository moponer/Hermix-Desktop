## 一、对话界面（核心交互）

### 1.1 头像与时间显示规则
- 默认走 hermix 内置头像。
- 用户切换专家后，**新产生的消息**（专家回复）显示该专家头像；**历史非专家消息**保持原头像与名称不变。
- 时间状态同理：切换专家前的消息时间显示不变，之后的按专家会话时间轴显示。

### 1.2 输入框功能栏调整
- 撤销 / 重做按钮**取消**。
- 上传入口从"图片"改为"文档图片"，支持任意文档与图片，不限图片类型。

### 1.3 润色功能
- 位置：语音按钮右侧新增"润色"图标。
- 行为：点击后调用内置"提示词润色专家"重新整理输入内容，结果**覆盖**到对话输入框。
- 上下文策略：用户最终点发送时，**润色前的原文抛弃**，不计入对话上下文，只把润色后内容作为发送源。
- **Prompt 模板**：单独维护一套"对话场景润色"模板（侧重自然语言流畅、意图清晰、避免重复），**不与 7.1 自动化 PROMPT 共用**。

### 1.4 拖放附件
- 对话输入框支持拖放任意受支持文件。
- 拖入后默认作为上传附件，遵循现有的附件处理流程。

### 1.5 工作目录锁定
- 一旦确认工作目录，**当前对话内不可更换**。
- 原因：已发生的读写动作受原目录限制，切换会让原有限制失效。
- 解锁条件：开新对话才能改目录。

### 1.6 工作目录 UI 呈现
- 选好后**只显示目录名称**（不要"目录:xxx"这种前缀格式）。
- 状态：灰色不可选取。
- **无关闭按钮**（避免视觉上暗示可切换）。
- 整体传递"已锁死、不可改"的视觉信号。

## 三、工作区与群聊列表（侧边栏第二级）

### 3.1 工作区列表项视觉规范
- **最左**：文件夹图标。
- **中间**：工作区名称（如"安全工作"）。
- **右侧**：统计数字（该工作区下对话数量）。
- **最右**：展开 / 收起箭头。

### 3.2 群聊/聊天室列表项视觉规范（与工作区同级）
- **最左**：图标（按聊天室类型识别）。
- **中间**：聊天室名称。
- **右侧**：统计数字（该聊天室下会话数量）。
- **最右**：展开 / 收起箭头。
- **加号（创建入口）保持不变**——工作区与群聊各自的"+"创建按钮位置不动。

### 3.3 对话列表项状态显示
- **非激活项**：右侧显示相对时间（"2 天前""15 天前"）。
- **正在对话的（激活项）**：用一个小圆点标识，**不显示时间**（或时间替换为激活点）。

## 四、群聊/聊天室

### 4.1 对话框复用 + 差异
- **复用方式（已确认）**：走**组件抽离**——把单 Agent 对话框拆出可复用子组件（输入框、工具栏、附件槽等），群聊与单聊各自组装。
- **复用部分**：输入框、工具栏（润色、语音、拖放、附件等）、基础消息能力。
- **专家头像切换**：保留，但**去掉授权限制**——多 Agent 场景下自由切换。
- **拖放功能**：照搬。
- **消息渲染**：**必须单独做**——多 Agent 群聊消息与单 Agent 对话的消息结构不同，渲染逻辑独立。

> **实施含义**：单 Agent 对话框要按可复用粒度重构（输入区、工具栏、附件 chip、消息气泡等尽量做成纯组件 + props 注入），不要把群聊对话框"塞进"单聊里调用，避免后续两边改动互相牵制。

### 4.2 总管消息样式
- 现状：总管消息有自己的特殊排版。
- 目标：总管消息排版与其他成员**保持一致**，仅在头像 / 名称上区分身份。
- 目的：减少群聊中的视觉割裂感。

## 五、扩展中心（4 个界面统一规范）

涉及：插件、技能、技能连接器、工具集。这 4 个界面位于同一扩展菜单下，统一按以下规则处理。

### 5.1 顶部标题与二级标题
- **顶部标题**：4 个界面**分别用各自名字**——
  - 插件 → "插件"
  - 技能 → "技能"
  - 技能连接器 → "连接器"
  - 工具集 → "工具集"
  - 不再统一写"扩展中心"。
- **二级标题**：原"启用工具技能与连接器..."类统一文案，按界面分别改为该界面专属文案（例：插件页写"启用插件"，技能页写"启用技能"，连接器页写"启用连接器"，工具集页写"启用工具集"）。

### 5.2 官方插件市场列表项
- 左侧图标：调整。
- 右侧图标：调整。
- 边框线：去除。
- 具体图标设计方案王爷后续指定。

### 5.3 技能界面列表项
- 左侧图标 + 右侧图标：都要调整。
- 边框线：是否也去除（**待确认**）。

### 5.4 连接器工具集图标
- 边框线：本就**无边框线**，不用改。
- 每个连接器 / 工具项的图标**各不相同**，要单独设计。

## 七、自动化

### 7.1 新建自动化页 — PROMPT AI 生成
- 位置：新建自动化页的 PROMPT 输入区。
- 新增"AI 生成"按钮。
- 行为：用户描述大概情况 → AI 润色改写 → 回填到 PROMPT 输入框。
- 与"对话润色"的差异：场景在自动化配置页，提示词偏结构化（角色、目标、约束、输出格式等）。
- **Prompt 模板**：单独维护一套"自动化 PROMPT 改写"模板（侧重结构化、变量占位符保留、可执行性强），**不与 1.3 对话润色共用**。
