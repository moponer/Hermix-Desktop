## 0. 修订说明：v2 哪些被推翻

用户对 v2 原型逐条审阅后，**三处结构性提议被否**。这里写清楚，避免以后重提：

| v2 提议 | 结论 | 原因 |
|---|---|---|
| 侧栏改成「今天 / 昨天」时间分组 | **撤销，保持原样** | 现有「对话 N / 项目 N」可折叠分组 + 项目嵌套会话，是成熟的信息架构。时间分组会把项目和它们的会话拆散 |
| 产物改成右侧滑入浮层（无遮罩） | **撤销，保持停靠** | 浮层的阴影和边框让画面变乱；停靠栏可拖宽度、有 tab 结构，本身更好用。只补一个折叠态 |
| 输入区改成「纯打字 + 斜杠命令面板」，元信息上移到顶栏 | **撤销，保持原样** | 专家 / 目录 / 权限 chip 在输入区旁边是高频操作位，不是常量噪音。搬到顶栏反而多一次视线跳转 |

**保留下来的** v2 提议：配色重做、正文行宽收窄、思考跑完即收、工具去卡片化、
审批卡收敛为唯一朱砂、工作台悬浮在场球。

## 1. 五处真正要改的

### 1.1 正文行宽：920px → 640px（最实在的一处）

现状 `.msg-stream-list` 是 `max-w-[800px] lg:max-w-[800px] xl:max-w-[920px]`
（`MessageList.tsx:321`）。14px 字号下：

- 920px ≈ 每行 **65 个汉字**
- 640px ≈ 每行 **38 个汉字**

65 字/行超出了中文正文的舒适行长（35–45 字），眼睛回扫时容易串行——这是"读久了
累"最直接的可测原因。原型屏 ③ 用同一段文字叠了 640px 虚线做对照。

**只收窄正文这一层**：代码块、表格、长命令行保持原宽度并允许横向滚动。
用户气泡同步收窄（`max-width: 80%` → 跟随 measure）。

改动落点：`MessageList.tsx` 的 `max-w-*` 一处 + `components-prose.css` 的
`.prose` 兜底宽度。

### 1.2 思考块：跑完即自动收起

现状行为是"思考结束后保持展开"（用户截图里就是展开态）。改为：

| 时刻 | 行为 |
|---|---|
| 思考进行中 | 展开显示实时内容，竖线缩进、无背景块 |
| 进入工具调用 / 开始输出正文 | **200ms 内自动收成一行**：`◍ 思考 · 持续了 3.2 秒 ⌄` |
| 用户手动点开过 | 本轮内保持展开，不再自动收 |
| 下一轮开始思考 | 重置为展开，走同样逻辑 |

状态只存在当前轮的 React state 里，不持久化、不迁移。
收起的思考行与"已完成一轮"的行视觉同族：一行 mono 时长 + 可展开。

### 1.3 工具调用：去卡片化

保留现有 rail（竖线 + 状态点）思路，但：

- 工具行**永远不出现卡片边框/底色**
- 一行内容：`状态点 + mono 工具名 + 参数预览(省略号截断) + 右侧结果摘要`
- 状态点 7px：成功=空心绿、运行=朱砂实心、失败=实心红
- 命令输出默认显示**最后 3 行**，hover 出复制/全屏，展开才是终端面板
- 子代理折叠为一行 `子代理 · 代码审查 · 完成`

### 1.4 审批卡：收敛为全屏唯一朱砂

现在审批卡是玻璃卡片（backdrop-filter + 双 inset 阴影），和待办卡、总结卡
不是一个语言但也分不出主次。改为：

- 2px 朱砂左边条 + `--color-bg-card` 底（恒比纸面亮 = 抬起）
- 标题「需要你的决定」（不是工具名 + 状态）
- 正文一句话说清**动作 + 影响面**（写哪几个文件、覆盖还是新增）
- 按钮右对齐：`取消`(ghost) / `允许`(实心朱砂)，动词不用「是/否」

**判据**：一屏之内朱砂只出现在这里 + 正在运行的那一个工具点上 + 主发送按钮。
满屏三个朱砂元素就说明规矩破了。

### 1.5 产物栏：只加折叠态

保持停靠（320–520px 可拖、顶部 `产物/电脑` tab、列表项带文件类型图标与
「改写 · 18 KB」元信息）。**只增加**：

- 折叠态 = 44px 竖条，顶部一个 30px 圆角图标 + 朱砂数量角标 + 竖排「产物」二字
- 收起后仍留在原位，点一下原路展开，宽度记忆
- 不引入浮层、不引入遮罩、不改变 tab 结构

## 2. 配色（已落地到代码）

两套主题，深度语法同构。三个关键决定与旧版不同：

1. **卡片恒比背景亮**。旧版 `--color-bg-card` 与 `--color-bg-primary` 同为
   `#faf9f5`——卡片根本没抬起来，层次只能靠到处画边框，这就是满屏盒子感的来源。
2. **正文对比降一档**（`#2b2a27` on `#f7f5f0` ≈ 11.5:1，而非 21:1）。墨水屏
   久看不累正是因为没有高对比造成的光晕。
3. **暗色推翻"中性轴必须 R=G=B"铁律**，改为允许色相、饱和度上限 4%。
   纯中性灰是暗色"水泥感"的直接来源；底色从纯黑 `#0b0b0b` 提到 `#121419`。

| 层 | 宣纸 | 夜墨 |
|---|---|---|
| 案（侧栏/顶栏/最外层） | `#edeae2` / `#f0eee7` | `#1a1d23` / `#0f1115` |
| 纸（对话区） | `#f7f5f0` | `#121419` |
| 面（卡片，恒比纸亮） | `#fcfbf8` | `#181b21` |
| 浮（弹层/菜单） | `#ffffff` | `#232833` |
| 墨（朱砂） | `#be4a32` | `#e06a4c` |
| 正文 | `#2b2a27` | `#e9eaee` |

语义四色彼此拉开 ≥30° 色相且全部避开朱砂橙区：
松绿 `#2e7a54` / 芥黄 `#96750f` / 绛红 `#a32b54` / 靛灰 `#5b6b7a`。

- **输入栏**：输入框 + 下方 chip 工具条（专家 / 目录 / 权限 / 附件 / 发送）

- **产物栏**：停靠三列、tab 结构、可拖拽调宽

- **右栏默认宽度逻辑**：沿用现有 resize 逻辑
