# Decision Note: 阿黎页改为值守大屏，主色由松墨绿换为墨蓝

Status: implemented — 主题换色、墨绿主题下架、大屏双态落地（2026-10-24）

## Decision

### 1. 主色：松墨绿 → 墨蓝

`--color-accent` 浅色 `#1e4a3c` → `#2f4a63`，深色 `#6fae94` → `#9dbdd8`；`on-accent`、`link`、`btn-primary-*` 一并对齐。派生键（`accent-soft` / `accent-soft-strong` / `accent-line` / `accent-hover` / `bg-selected` / `bg-hover-subtle`）全部由 `color-mix` 从 accent 推导，无需逐个改。

实测对比度（WCAG）：浅色 9.21（白底）/ 7.79（app 底）/ 8.52（卡片）；深色 9.39（`#141414`）/ 8.40（卡片）；accent 文字落 soft 底 5.04~6.3。`check-theme-tokens` 全绿。

### 2. 墨绿主题下架

删除 `styles/themes/ink-green.{css,json}`。registry 是 `import.meta.glob` 自动发现，删文件即从切换器消失；`ThemeMode` 为 `string`，无枚举需改。它的中性轴是绿灰、且取自移动端 `uni.scss` 的令牌映射，继续换色等于重做整套——下架比改造便宜。

### 3. 阿黎页改为值守大屏

版面从「三栏信息板 + 底部单行输入」改为「顶栏 / 中轴双态 + 两翼 / 底条」：

- **中轴是双态面板**：默认对话；出现待审批时自动切到数据态（同一件事只切一次），点「回到对话」或让输入框获得焦点切回，手动切回后 30s 内不再被自动切走（`AUTO_SWITCH_COOLDOWN_MS`）。
- **两翼承载数据**：左翼是「她替你看着什么」（任务条、四项指标、最近会话、工作日志），右翼是「现在要你做什么」（待审批、刚发生的事、她的状态）。
- **数据纪律不变**：环上的百分比只在任务有 `max_runs` 时出现，否则只报在跑的个数与次数，不编造进度；情报源与成长档案仍未接通，对应位置不再铺占位卡，改为一句说明。
- **零渐变**：进度、环、按钮、装饰线全部实色；面板分区靠 `bg-primary/card/tertiary` 三层底色，不画中性描边（G11 的 12 处新增描边已全部换成分层底色）。

## Alternatives considered

- **只换 accent、保留三栏卡片**：卡片墙的问题不是配色，是「按数据表分栏」——五张卡里三张空态，用户一进来看到 60% 是「待接通」。换色解决不了这件事。
- **保留墨绿主题一起改**：它的中性轴、移动端映射、对比度注释都是按墨绿调的，改造成本 = 重做一套主题，且第三套主题本身没有明确的用户场景。
- **靛蓝 `#2b45c7` 作主色**：C≈0.19 太高，大面积铺开会被读成「链接蓝/品牌蓝」，且给数据染色。墨蓝 C≈0.055 更接近中性，能把「彩色」留给状态。
- **大屏沿用「发光 + 渐变」的科技风**：与产品「纯中性、零色相」的既有纪律冲突，且浅色主题下发光会糊成脏边。

## Consequences

- **正面**：主色与状态色（success/warning/error）色相距离拉开到 150°+，异常不再被主色吃掉；中轴双态让「有事时看数据、平时说话」两种任务不再互相挤占；面板不画线后，换背景图/视频时不会出现「线压图」的脏边。
- **代价**：`components-twin.css` 里旧三栏的样式（`.twin-view` / `.twin-board` / `.twin-col*` / `.twin-card*` / `.twin-presence*` / `.twin-readout*` / `.twin-transcript*` / `.twin-dock*` / `.twin-pending*` / `.twin-learn*` / `.twin-bar` / `.twin-dot` / `.twin-perm` / `.twin-state` / `.twin-chip` / `.twin-tag`）已成死代码，约 600 行，尚未清理——删之前要有人肉眼复核一遍，避免误删仍在用的 `.twin-error` / `.twin-need__input`。
- **命名坑**：旧 `.twin-task` 带 `padding: 9px 11px 10px` 与面板底色，与新大屏的任务行同名不同义，直接叠加会把每行撑成嵌套方块。新任务行整族改名为 `.twin-job`。以后在同一个文件里复用类名前，先 grep 一遍有没有同名旧规则。
- **未验证**：本轮只跑了 `tsc` 与三个门禁脚本，**没有实际启动桌面端看画面**。空态、长任务名、长会话标题在真实数据下的排版需要肉眼过一遍。
