## 1. 视觉主题与氛围

深色工程感产品站。底子是**冷灰黑**（不带棕也不带蓝的近黑灰），
重音只有一个 **teal**。层次由三层表面明度阶梯 + 发丝边框承担；
渐变共两处授权：**页面级流光层**（fixed 光斑慢旋，透明度 ≤ .07）与
**首屏品牌色辉光**（径向渐变，呼吸动画）；玻璃拟态只给吸顶导航——
这是当代开源官网的通用语汇，不再有第三处。

气质关键词：深夜终端、专业工具、被认真打磨的开源项目。
「数据在本机、不设服务器」的主张不变，视觉上依然克制、可审计、无推销感。

**记忆点**：暗底上唯一的 teal 辉光，以及每个产品页首屏那块**高保真界面预览**
——它让「这是个桌面应用」这件事在三秒内成立。

### DNA 注入（逐值可溯源）

| 偷来的值 | 出处 |
|---|---|
| 冷灰黑三层表面阶梯 + 发丝边框 | Linear / Shadcn dark 通用结构 |
| 首屏单点径向辉光（品牌色，透明度 ≤ .13） | Supabase / Linear hero glow |
| 玻璃拟态吸顶导航（blur + 半透明 + 发丝底线） | 当代开源官网通用 |
| Teal 重音 `#3fd0b6`（2026-10-18 主人拍板，由暖橙陶土换冷色） | 当代开源工具站主流重音 |
| 阴影多层累积、黑染透明度低 | `design-systems/notion` §2 Shadows & Depth |
| 卡片圆角 12px / 按钮 8px | `design-systems/notion` §5 Border Radius Scale |

## 2. 色板与角色

```css
--paper:      #0f1115;  /* 页底：冷灰黑 */
--paper-2:    #15181d;  /* 卡面 / 抬高面 */
--paper-3:    #1d2127;  /* 次级填充：hover 底、输入底 */
--line:       #2b3038;  /* 发丝线：分区、卡片边框 */
--line-soft:  #1f242b;  /* 最轻分区：列表行分隔 */
--ink:        #e9edf2;  /* 主文字 ~13:1 */
--ink-2:      #a8b1bd;  /* 次级文字 ~7:1 */
--ink-3:      #7d8794;  /* 元信息 ~4.6:1 —— 全站最浅文字，不可再浅 */
--clay:       #3fd0b6;  /* teal 重音：主 CTA、链接、当前项（变量名沿用旧称） */
--clay-deep:  #2bb39a;  /* hover / 按压 */
--clay-soft:  rgba(63,208,182,.12);  /* teal 浅底（半透明，随底色融合） */
--glow:       rgba(45,190,160,.13);  /* 首屏辉光专用，仅此一处 */
```

**对比度底线**：`--ink-3` ≈ 4.6:1 on `--paper`，是全站最浅文字下沿，再浅只能做装饰。
按钮字色用 `#07211b`（深青黑），白字在 teal 底上对比不足。

**禁色**：slate / indigo / violet / purple 全族禁用（P-39 延续）；
冷灰底允许，但重音只用 teal 一个色相。
自检法：hex 的 B 通道明显高于 R/G 且偏紫即违规。

**语义色**（仅状态使用）：成功 `#7fae6d`、警告 `#d99a4e`、错误 `#e06a6a`。

## 3. 排版规则

字体不变：正文/UI 系统栈，代码 `ui-monospace`。**不引入任何 webfont**。

| 角色 | 字号 | 字重 | 行高 | 字距 |
|---|---|---|---|---|
| H1（首屏） | `clamp(32px, 4.2vw, 46px)` | 650 | 1.22 | -0.02em |
| H2（section） | `clamp(21px, 2.2vw, 26px)` | 600 | 1.35 | -0.015em |
| H3 | 18px | 600 | 1.45 | -0.008em |
| 引导句 `.lead` | 17px | 400 | 1.70 | 0 |
| 正文 | 15px | 400 | 1.72 | 0 |
| 文章正文 | 16px | 400 | 1.85 | 0 |
| 元信息 | 13.5px | 400 | 1.68 | 0 |
| badge | 12px | 500 | 1.33 | +0.125px |

规则（延续）：
- 字重只用 400 / 500 / 600 / 650；**不用斜体**（P-1）
- 深色底上标题可以比亮色版更大更重——这是当代深色官网的第一观感
- `.lead` 必须 ≥ 正文；中文行高 ≥ 1.5；中西文之间加空格
- 数字与版本号一律 `tabular-nums`

## 4. 组件样式

### 按钮
- 主：底 `--clay`，字 `#1a120c`（深炭，非白），8px 圆角，`padding: 10px 22px`，13.5px/600
- 次：透明底 + `--line` 边框 + `--ink` 字；hover 边框转 `--clay`、字转 `--clay`
- **禁用态**：底 `--paper-3`，字 `--ink-2`，并给出原因与解锁路径
- 反馈：hover 换底/换边 140ms；`:active { transform: scale(.97) }`；无 `transition: all`

### 容器与分区
- `--container: 1160px`；section 纵向加大呼吸感 `clamp(56px, 7vw, 96px)`
- 分区**靠留白**，全站取消 section 间横贯发丝线（深色底上密线显碎）；
  卡片自身仍保留 1px `--line` 边框
- 卡片：底 `--paper-2`，12px 圆角，内距 22–26px；列表/特性仍用 `border-top` 分区

### 选中态 / 强调
- **禁止左侧竖线**（P-38）：当前项 = `--clay-soft` 底 + teal 字 + 600 字重
- callout / note：`--clay-soft` 或 `--paper-3` 底 + 全边框
- 焦点环：`2px solid var(--clay)`，仅 `:focus-visible`

### 玻璃导航（全站唯一玻璃拟态）
- `background: rgba(22,20,18,.72)` + `backdrop-filter: blur(14px)` + 底线 `--line`
- 深色玻璃上必须自带底线，否则滚动内容从底下穿过时分界消失

### 徽标 / 标签
12px / 500 / +0.125px 字距，`--paper-3` 底 + `--ink-2` 字。不用 emoji（P-40）。

### 会话重放（trace 演示幕）
- 复用 `shot-*` 视觉语言，字号放大到正文级（消息 13px、工具行 12px）
- 步骤入场只动 `transform` / `opacity`，由 `.js` 类门控——JS 不可用时步骤静态全可见
- 「已思考」折叠用原生 `<details>`（零 JS 交互）；入场动画全局有
  `prefers-reduced-motion` 兜底
- 幕内审批按钮是真实交互语义，字号 ≥ 12.5px，不吃拟真免责
- **演示内容红线**：只演示产品真实存在的能力（工具调用、审批、会话留痕），
  不得把演示形态写成产品功能（如「回放」按钮这种产品没有的东西）；
  头部标注「演示」；数字（耗时、行数）必须与产品真实能力一致，不编造；
  **场景选大众痛点**（磁盘空间、重复文件、整理下载夹），不放行业专属场景

### 界面预览活细节
- 动态光三层：**页面流光层**（`body::before` fixed，三块 teal 光斑，
  `rotate ±2.5deg + scale 1→1.05`，36s 往返——只动 `transform`，不扫不位移）+
  hero 辉光慢呼吸（`opacity` .55→1，7s）+ 输入框光标闪烁（`steps(1)` 1.1s）
- **无限位移动画禁止**（impeccable 判 marquee），进度条保持静态
- 流光层透明度单块 ≤ .07；它是氛围不是内容，任何文字区不受它干扰（z-index:-1）

### JS 边界（零构建约束下的口径）
`public/` 静态站**允许手写 vanilla JS**（site.js / qrcode.min.js / 播放器皆此），
禁止的是：npm 依赖、打包器、框架运行时。演示类交互（滚动触发、重放）用
原生 `IntersectionObserver` + `setTimeout` 实现。

## 5. 布局原则

- 基准 8px：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96
- **首页与产品页首屏分工**（2026-10-19 拍板）：首页是门厅——宣言式纯排版 hero
  （眉行 kicker + 大主张 + 信任行），**不放界面预览**，内容是品牌层
  （三条底线：不设服务器 / 先划界再放行 / 远程不失控），不复制产品页的功能清单；
  产品页（hermix.html）是展厅——界面预览、演示幕、功能清单、下载都在那边。
  两页内容不得高度重合
- **首屏非对称**：文字 + 界面预览双列，禁止居中 Hero、禁止三等分卡片横排
  （首页宣言 hero 为单列特例）
- 首屏预览外加**辉光晕**：`.hero` 上一层径向渐变（品牌色，≤.16 透明度），
  只许出现一次
- 文档/阅读页：侧栏 236px + 正文，容器居中
- 窄屏（<900px）非对称一律塌缩单列

## 6. 深度层级

| 层 | 处理 | 用途 |
|---|---|---|
| 0 平 | 无边框无阴影 | 页底、纯文本 |
| 1 含 | `1px solid var(--line)` | 卡片、预览窗 |
| 2 抬 | `0 1px 2px rgba(0,0,0,.3), 0 8px 24px rgba(0,0,0,.25)` | 可交互卡片 hover |
| 3 浮 | `0 2px 8px rgba(0,0,0,.3), 0 16px 48px rgba(0,0,0,.35)` | 界面预览、浮层 |

深色主题阴影改为**真正的黑**（暗底上染暖透明的旧公式不可见），单层透明度 ≤ .35。

## 7. Do's / Don'ts

**Do**
- 冷灰黑底 + 单一 teal 重音；辉光只给首屏一处；玻璃只给导航一处
- 每个产品页首屏保留**高保真界面预览**（深度 ≥ 3 层、元素 ≥ 8、有活细节）
- 版本、SHA、日期现取现填，取不到就如实说
- 动效只做反馈级：120–240ms，`cubic-bezier(.23,1,.32,1)`，只动 `transform` / `opacity`

**Don't**
- 不用蓝紫（P-39）；渐变只有流光层与首屏辉光两处授权，其余禁用
- 不用斜体（P-1）、不用 emoji（P-40）、不用左侧竖线（P-38）
- 不用三等分卡片横排；section 间不画横贯线
- 不写"革命性 / 颠覆 / 无缝 / 赋能"；感叹号一页 ≤ 1
- 不用 `transition: all`、不加 `ease-in`、不省略 `prefers-reduced-motion`

## 8. 响应式

| 断点 | 变化 |
|---|---|
| <640px | 单列；H1 落到 32px；导航折汉堡；二维码居中 |
| 640–900px | 特性双列；客户端区单列；文档侧栏转横排目录 |
| 900–1200px | 完整非对称 |
| >1200px | 容器锁 1160px 居中 |

触控目标 ≥ 44×44；移动端禁横向滚动；表格包 `overflow-x:auto`。

---

## 9. Motion 哲学

不变：动效强度 4/10，只做反馈不做表演。缓动 `cubic-bezier(.23,1,.32,1)`；
时长 120–240ms 上限 300ms；hover 包 `@media (hover:hover)`；
全局 `prefers-reduced-motion` 兜底；只动 `transform` / `opacity`。
