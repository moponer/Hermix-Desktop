- 现象/根因：sccache 报 "Failed to create temp dir"；`<TMPDIR>` 残留 `Everyone:(CI)(DENY)(S,DC)` 显式 DENY 优先于 ALLOW，建临时目录必败
- 收口动作（一次到位）：
  1. `icacls <TMPDIR> /remove:d *S-1-1-0` 生效（SID 形式），复查 `icacls` 输出 DENY 行已消失
  2. `.cargo/config.toml` 第 7 行恢复 `rustc-wrapper = "<USERPROFILE>/.cargo/bin/sccache.exe"`（去掉暂禁注释）
  3. **额外修复**：此前该文件存在两个 `[env]` 段（R1 备选方案新增的第二个），所有 cargo 命令 TOML `duplicate key` 直接失败；已把 TEMP/TMP 覆盖合并进第一个 `[env]`。TOML 双引号串里反斜杠 Windows 路径触发 `\U` unicode 转义错误，改用正斜杠 `<USERPROFILE>/AppData/Local/Temp`。现 TEMP/TMP 覆盖与移除 DENY 双保险并存
- 验证：`cargo metadata --no-deps` 解析 OK；`cargo check -p hermix-desktop` Finished 零警告；`sccache --show-stats` 显示 Cache location 切到 `H:/sccache-cache`、Compile requests 3（wrapper 确实介入）
- 该文件已移出 git 跟踪 + gitignore，不入库、无需提交

## 6. 关键约定与坑（必读）

- **桥接编辑**：`crates/` 文件用 `apps/desktop-tauri/.tmp-edit/` 中转（cp → edit_file → cp 回）；`apps/desktop-tauri/src-tauri/` 与前端 `src/` 在沙箱内可直接编辑
- **Gitee 快照流程**：删 gitee-snapshot 分支 → `git checkout --orphan gitee-snapshot` → 单提交 → 强推 `gitee gitee-snapshot:main` → checkout main。非 checkout（已删文件会 pathspec 中断）
- **Windows curl 中文 body**：直接命令行传中文会 GBK 乱码 → 用 UTF-8 文件 `--data-binary @file`（node writeFileSync 写）
- **GitHub API**：`moponer/hermix` 路径 307 重定向 → 直接用 `api.github.com/repositories/1283484756`；curl 需 `--ssl-no-revoke`（schannel 吊销检查失败）；凭据走 `git credential fill`（host=github.com）
- **沙箱边界**：`crates/` 与仓库根 `docs/` 在工作目录（apps/desktop-tauri）沙箱外 → crat​es 写用 .tmp-edit 桥接；仓库根的 git 操作用 bash（cd <repo> && git …）可执行
- **日志位置**：`<USERPROFILE>\.hermix\logs\`（agent.log / server.log / desktop.log / tools.log）——分析线上行为先看这里
- **golden 快照**：directions.rs 的 EXPECTED_HASH 在有意改提示词后必须同步（新 hash 打印在断言失败信息里）
- **脱敏纪律**：新增代码不得含 `<repo-parent>`、`Administrator` 等本机路径；测试输入避免 `<>` 尖括号占位符（HTML 属性序列化转义会弄断断言）
- 后台任务槽上限 64；bash 单次 300s 上限（长测试用 bash_start 或过滤子集；hermix-agent 全量测试曾三次超时，用改动面覆盖的过滤子集代替）
