# PPT 设计系统

## 设计哲学

借鉴 oh-my-ppt 的核心设计理念：

1. **JSON 中间表示** — LLM 生成结构化内容 JSON，工具负责视觉渲染
2. **主题驱动** — 预设 6 套专业主题，每个主题包含配色、字体、布局网格
3. **内容高度预算** — 每个文本框有最大字符数限制，防止溢出
4. **布局一致性** — 9 种幻灯片布局，每种有固定的元素位置和大小

## 工作流程

### 第 1 步：理解需求

确认以下信息：
- **主题**：PPT 讲什么
- **场景**：产品发布、技术分享、学术答辩、商业汇报、课件
- **页数**：8-15 页最佳（15 分钟演讲）
- **风格偏好**：如果用户没指定，根据场景推荐

### 第 2 步：选择主题

根据场景推荐主题：

| 主题 | 风格 | 适用场景 |
|------|------|----------|
| `midnight` | 深蓝底+白字 | 科技/商务、产品发布、技术分享 |
| `aurora` | 渐变紫底+白字 | 创意/设计、品牌展示、创意提案 |
| `clean` | 白底+深灰字 | 极简/学术、论文答辩、数据报告 |
| `warm` | 暖米底+棕字 | 文艺/教育、课件、读书分享 |
| `carbon` | 纯黑底+亮字 | 高端/极客、技术架构、安全报告 |
| `ocean` | 深青底+白字 | 清新/环保、可持续发展、海洋主题 |

### 第 3 步：规划大纲

**从第一性原理出发**：一份好的 PPT 的物理约束是什么？

- 听众注意力 ~15 分钟 → 最多 15 页
- 每页停留 ~1 分钟 → 每页核心信息 ≤ 5 个要点
- 人脑短期记忆 7±2 → 每页要点 ≤ 6 个
- 阅读距离 3-5m → 标题 ≥ 28pt，正文 ≥ 16pt

标准大纲结构：

```
1. 封面 (title)        — 标题 + 副标题
2. 目录 (content)      — 3-5 个章节
3. 章节1 (section)     — 章节标题
4-6. 内容页 (bullets/content) — 每节 2-3 页
7. 章节2 (section)
8-10. 内容页
11. 引用/金句 (quote)   — 点睛之笔
12. 总结 (bullets)     — 3 个要点
13. 结尾 (closing)     — Thank You + 联系方式
```

### 第 4 步：生成 JSON 规格并调用工具

将大纲转换为 `create_presentation` 的 JSON spec：

```json
{
  "theme": "midnight",
  "file": "Q4-Report.pptx",
  "title": "2024 Q4 业务汇报",
  "slides": [
    {
      "layout": "title",
      "title": "2024 Q4 业务汇报",
      "subtitle": "增长 25%，创历史新高"
    },
    {
      "layout": "content",
      "title": "目录",
      "body": ["一、业绩概览", "二、关键指标", "三、挑战与对策", "四、下季度计划"]
    },
    {
      "layout": "section",
      "title": "一、业绩概览",
      "subtitle": "Q4 核心数据"
    },
    {
      "layout": "bullets",
      "title": "核心指标",
      "body": [
        "营收 5.2 亿，同比增长 25%",
        "新增客户 1,200 家",
        "NPS 评分提升至 72 分",
        "产品交付准时率 98%"
      ]
    },
    {
      "layout": "two_column",
      "title": "同比分析",
      "body": ["Q3: 营收 4.1 亿\n客户 950 家\nNPS 65", "Q4: 营收 5.2 亿\n客户 1200 家\nNPS 72"]
    },
    {
      "layout": "quote",
      "quote": "数据驱动的决策，让增长成为习惯。",
      "attribution": "CEO 季度寄语"
    },
    {
      "layout": "closing",
      "title": "Thank You",
      "subtitle": "contact@company.com"
    }
  ]
}
```

### 第 5 步：预览与迭代

生成后，用 `office_cli` 截图预览：

```
office_cli(action="view", file="Q4-Report.pptx", mode="screenshot")
```

如果需要调整：
- **修改单页**：`office_cli(action="set", file="...", path="/slide[3]/shape[2]", props=["text=新内容"])`
- **添加页面**：`office_cli(action="add", file="...", parent="/", type="slide", props=["title=新页"])`
- **重新生成**：修改 JSON spec 后重新调用 `create_presentation`

## 设计原则

### 内容预算（oh-my-ppt 核心算法）

每种文本元素有最大字符数限制：

| 元素 | 字号 | 最大字符 | 说明 |
|------|------|----------|------|
| 标题 | 28-44pt | 40 字 | 一行内完成，不换行 |
| 副标题 | 20pt | 80 字 | 最多两行 |
| 要点 | 18pt | 60 字/条 | 最多 6 条 |
| 正文 | 16-18pt | 200 字 | 大段文字 |
| 引用 | 28pt | 120 字 | 居中显示 |

**如果内容超出预算，必须拆分到多页。**

### 配色规则

- 标题色：高对比度（深底用白/浅色，浅底用深色）
- 正文色：中等对比度（深底用浅灰，浅底用中灰）
- 强调色：从主题的 5 个 accent 中循环取用
- 背景：主题背景色，不加额外装饰

### 布局规则

- **16:9 画布**（25.4cm × 14.29cm）
- **安全边距**：上下左右各 1.5cm
- **标题区**：顶部 1.0-2.5cm
- **内容区**：3.5-11.5cm
- **页脚区**：12.0-13.5cm（可选）

### 字体规则

- 中文统一用"微软雅黑"（clean/warm 主题除外）
- 等宽字体用"Consolas"（carbon 主题）
- 不混用多种字体

## 对抗性审查：什么情况下会出问题？

1. **内容过长** → 文字溢出文本框 → 解决：严格遵守内容预算，超长就拆页
2. **officecli 不可用** → 工具报错 → 解决：提示用户检查 binaries 目录
3. **特殊字符** → shell 转义问题 → 解决：工具内部已处理转义，但避免使用 `$`、`` ` ``
4. **图片路径** → 相对路径找不到 → 解决：使用绝对路径
5. **页数过多** → 命令执行超时 → 解决：工具设 60s 超时/命令，如需更多页可分批

## 常见问题

### Q: 可以生成动画吗？
A: 当前版本自动添加 fade 过渡效果。如需复杂动画，生成后用 `office_cli` 手动添加。

### Q: 可以插入图表吗？
A: 可以。先用 `office_cli` 添加 chart 元素，然后设置数据。或者在 spec 中使用 `data` 布局预留位置。

### Q: 支持中文吗？
A: 完全支持。所有主题默认使用微软雅黑字体。

### Q: 如何导出 PDF？
A: 生成 .pptx 后，使用 `office_cli(action="view", file="...", mode="html")` 导出 HTML，或用 PowerPoint 打开另存为 PDF。
