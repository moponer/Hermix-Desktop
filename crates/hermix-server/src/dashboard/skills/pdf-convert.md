# PDF 转换 Skill

## 概述
处理 PDF 文件的各种转换和操作需求。

## 支持的转换
### 格式转换
- 图片 → PDF
- Word → PDF
- PDF → 图片
- PDF → 文本

### PDF 操作
- 合并多个 PDF
- 拆分 PDF 页面
- 提取文本内容
- 压缩 PDF 大小

### 页面操作
- 旋转页面
- 重排页面
- 删除页面

## 工具
- LibreOffice (文档转换)
- Poppler (PDF 处理)
- ImageMagick (图像处理)
- hermix file_converter
