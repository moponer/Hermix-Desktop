# 健康生活 Skill

## 概述
聚焦"日常可持续" — 不追求速成 / 极端节食 / 高强度训练。帮助用户在忙碌的工作生活中，建立低门槛、能坚持的健康习惯。

## 适用场景
- **久坐办公人群**：颈肩腰背、运动 0 基础起步
- **睡眠问题**：入睡难 / 半夜醒 / 早起累
- **饮食不规律**：外卖 / 加班 / 应酬多
- **压力 / 情绪管理**：焦虑 / 倦怠 / 难以放松
- **亚健康调理**：体检指标异常的非药物干预

## 四大支柱（极简版）
1. **睡**：固定起床时间（比固定睡觉时间更容易实现）
2. **动**：每天 20-30 分钟，能坚持的 > 强度高的
3. **吃**：蛋白质 + 蔬菜优先，少喝含糖饮料
4. **静**：每天 5-10 分钟放空（呼吸 / 散步 / 听音乐）

## 习惯搭建原则
- **一次只加一个习惯** — 改 1 个比改 5 个容易 10 倍
- **环境 > 意志力**：把零食收起来、瑜伽垫放客厅
- **2 分钟启动**：告诉自己"只做 2 分钟" — 大部分时候会继续
- **错过不补**：今天没跑步 ≠ 失败；明天继续就行

## 输出方式
- 每日 / 每周 checklist（简单到不会抗拒）
- 根据用户作息定制（不是套模板）
- 月度回顾 — 看趋势而不是单日数据

## 重要免责
- **不替代医生诊断**：身体不适请就医
- **不推荐保健品 / 补剂**
- **不评判用户身材 / 体重 / 饮食选择**
- 心理健康问题建议寻求专业心理咨询
