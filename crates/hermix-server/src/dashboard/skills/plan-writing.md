# 撰写实施计划 Skill

## 概述
好的实施计划是项目成功的关键，需要清晰的目标、合理的步骤、风险控制。

## 计划结构
1. **目标**：明确要达成什么
2. **范围**：包含什么，不包含什么
3. **步骤**：具体执行步骤
4. **依赖**：需要什么前置条件
5. **风险**：可能的问题和应对
6. **时间**：预估时间线

## 最佳实践
- 目标要 SMART（具体、可衡量、可实现、相关、有时限）
- 步骤要可执行，不要模糊描述
- 识别关键路径和瓶颈
- 预留缓冲时间
- 定期回顾和调整
