# 前端架构 Skill

## 概述
现代前端开发需要考虑架构设计、性能优化、用户体验。

## 框架选型
- React：生态丰富，适合大型应用
- Vue：易学易用，适合快速开发
- Angular：企业级，适合复杂应用

## 渲染策略
- CSR：客户端渲染
- SSR：服务端渲染
- SSG：静态生成
- ISR：增量静态再生

## 状态管理
- 本地状态：useState
- 全局状态：Redux, Zustand
- 服务端状态：React Query, SWR

## 性能优化
- 代码分割
- 懒加载
- 虚拟列表
- 缓存策略
