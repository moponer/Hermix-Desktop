# 会议纪要 Skill

## 概述
从会议录音或文字记录中提取关键信息，生成结构化的会议纪要。

## 会议纪要结构
1. **会议信息** — 时间、地点、参与人
2. **议题列表** — 讨论的主要话题
3. **关键决策** — 达成的共识和决定
4. **行动项** — 待办事项和负责人
5. **待讨论** — 未解决的问题

## 提取要点
- 发言人身份
- 核心观点
- 决策结果
- 分歧点
- 后续计划

## 格式要求
- 时间线清晰
- 责任人明确
- 截止日期具体
- 优先级标注
