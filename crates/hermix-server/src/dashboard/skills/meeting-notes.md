# 会议纪要 Skill

## 触发条件
当用户要求以下操作时使用此 Skill:
- "整理会议" / "会议纪要" / "meeting notes"
- "会议记录" / "会议总结"
- "提取要点" / "extract key points"
- "会议摘要"

## 执行步骤
1. 阅读会议记录/录音文本
2. 按结构提取关键信息
3. 生成结构化会议纪要

## 会议纪要结构
1. **会议信息** — 时间、地点、参与人
2. **议题列表** — 讨论的主要话题
3. **关键决策** — 达成的共识和决定
4. **行动项** — 待办事项和负责人
5. **待讨论** — 未解决的问题

## 输出格式
```
# 会议纪要

## 会议信息
- 时间: [日期]
- 参与人: [列表]

## 议题
1. [议题 1] — [讨论摘要]
2. [议题 2] — [讨论摘要]

## 关键决策
- [决策 1]
- [决策 2]

## 行动项
| 事项 | 负责人 | 截止日期 |
|------|--------|----------|
| [事项] | [负责人] | [日期] |

## 待讨论
- [未解决问题]
```
