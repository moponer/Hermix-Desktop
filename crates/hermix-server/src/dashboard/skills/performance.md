# 性能优化 Skill

## 触发条件
当用户要求以下操作时使用此 Skill:
- "优化" / "性能" / "performance"
- "分析瓶颈" / "find bottleneck"
- "提高速度" / "speed up"
- "内存优化" / "memory optimization"

## 执行步骤
1. 基准测试 — 建立性能基线
2. 性能分析 — 找出瓶颈（CPU/内存/IO）
3. 优化实施 — 针对性优化
4. 验证效果 — 确认优化有效

## 常见优化策略
### 算法优化
- 选择合适的数据结构
- 减少时间复杂度
- 避免不必要的计算

### 缓存策略
- 内存缓存、磁盘缓存、CDN 缓存

### 并发处理
- 异步 I/O、并行计算、连接池

### 数据库优化
- 索引优化、查询优化、批量操作

## 输出格式
```
## 性能分析报告
### 瓶颈
- [瓶颈描述] — [影响程度]

### 优化方案
- [方案描述] — [预期效果]

### 验证结果
- 优化前: [指标]
- 优化后: [指标]
- 提升: [百分比]
```
