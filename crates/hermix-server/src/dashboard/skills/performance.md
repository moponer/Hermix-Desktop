# 性能优化 Skill

## 概述
识别性能瓶颈并实施优化策略。

## 性能分析步骤
1. **基准测试** - 建立性能基线
2. **性能分析** - 找出瓶颈
3. **优化实施** - 针对性优化
4. **验证效果** - 确认优化有效

## 常见优化策略
### 算法优化
- 选择合适的数据结构
- 减少时间复杂度
- 避免不必要的计算

### 缓存策略
- 内存缓存
- 磁盘缓存
- CDN 缓存

### 并发处理
- 异步 I/O
- 并行计算
- 连接池

### 数据库优化
- 索引优化
- 查询优化
- 批量操作

## 工具
- perf (Rust/Go)
- Chrome DevTools (JavaScript)
- cProfile (Python)
- JMeter (负载测试)
