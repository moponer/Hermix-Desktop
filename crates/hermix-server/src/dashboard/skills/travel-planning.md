# 旅行规划 Skill

## 概述
帮助用户规划一次完整的旅行：从决定"去哪儿玩几天"到"回程前一天还在查什么"，覆盖行程、预算、住宿、交通、应急。

## 适用场景
- **周末短途**（2-3 天）：城市周边、轻装出行
- **国内长假**（5-10 天）：跨省深度游
- **出境旅行**（7-15 天）：多城市、签证、通讯
- **亲子 / 父母 / 团建**：特殊人群需求
- **自驾 / 自由行 / 半自由行**：不同模式的取舍

## 核心方法
1. **三段式确认**：先问预算、人数、天数、风格偏好；再给 2-3 个目的地对比；最后细化行程
2. **节奏感**：避免"每天排满 5 个景点"，保留空闲时段
3. **预算透明**：交通 + 住宿 + 餐饮 + 门票 + 应急，按类别列
4. **本地体验**：推荐非景点的咖啡店/市集/夜市 — 一座城市的味道往往在那里
5. **天气 / 季节**：根据出行时间给穿衣、防晒、雨具建议

## 关键提醒
- 节假日提前订住宿（价格差 2-3 倍）
- 出境：签证、电源转换、漫游 / eSIM、应急联系人
- 重要文件：电子 + 纸质双备份（护照、机票、酒店预订单）

## 不做的事
- 不替用户做高风险预订决策（不直接推荐买保险产品）
- 实时价格 / 余票 — 建议用户到对应平台确认

## 实践指南
1. 三段式确认：先问预算 / 人数 / 天数 / 风格，再给 2-3 个目的地对比，最后细化
2. 节奏感：别每天排满 5 个景点，留空闲
3. 预算透明：交通 + 住宿 + 餐饮 + 门票 + 应急分类列
4. 推荐本地非景点体验（咖啡店 / 市集 / 夜市）

## 注意事项
- 不替用户做高风险预订决策（不直接推荐买保险）
- 实时价格 / 余票让用户到平台确认
- 节假日提前订住宿，价差大
