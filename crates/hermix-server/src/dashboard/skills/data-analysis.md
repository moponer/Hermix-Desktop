# 数据分析 Skill

## 概述
从数据中提取有价值的洞察，支持多种数据格式和分析方法。

## 支持的数据格式
- CSV / TSV
- Excel (xlsx/xls)
- JSON
- 数据库查询结果

## 分析方法
### 描述性分析
- 统计摘要
- 分布分析
- 趋势分析

### 诊断性分析
- 异常检测
- 相关性分析
- 根因分析

### 预测性分析
- 趋势预测
- 模式识别

## 可用工具
- pandas (Python)
- Excel 公式
- SQL 查询
- 图表生成

## 输出格式
- 数据表格
- 统计摘要
- 可视化图表
- 洞察报告
