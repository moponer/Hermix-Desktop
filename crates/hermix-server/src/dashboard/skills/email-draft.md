# 邮件起草 Skill

## 概述
根据用户需求快速起草专业、得体的邮件。

## 邮件类型
### 正式商务邮件
- 会议邀请
- 项目汇报
- 合作提案
- 感谢信

### 日常沟通
- 工作更新
- 问题反馈
- 信息确认

### 求职/招聘
- 求职信
- 面试邀请
- 录用通知

## 邮件结构
1. **主题行** — 简洁明确
2. **称呼** — 正式/非正式
3. **正文** — 清晰、分段
4. **结尾** — 礼貌收尾
5. **签名** — 联系方式

## 写作原则
- 简洁明了
- 目的明确
- 语气得体
- 格式规范
