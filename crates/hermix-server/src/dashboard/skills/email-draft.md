# 邮件起草 Skill

## 触发条件
当用户要求以下操作时使用此 Skill:
- "写邮件" / "写封信" / "起草邮件"
- "email" / "draft an email"
- "回复邮件" / "reply to email"
- "商务沟通"

## 执行步骤
1. 确认邮件类型（正式/日常/求职）和收件人
2. 根据邮件结构模板起草
3. 检查语气和格式
4. 输出完整邮件文本

## 邮件类型
### 正式商务邮件
- 会议邀请、项目汇报、合作提案、感谢信

### 日常沟通
- 工作更新、问题反馈、信息确认

### 求职/招聘
- 求职信、面试邀请、录用通知

## 邮件结构
1. **主题行** — 简洁明确，一行说明目的
2. **称呼** — 正式/非正式（根据关系选择）
3. **正文** — 清晰、分段、重点突出
4. **结尾** — 礼貌收尾
5. **签名** — 联系方式

## 输出格式
```
主题: [邮件主题]

[称呼],

[正文段落 1]

[正文段落 2]

[结尾语],
[签名]
```
