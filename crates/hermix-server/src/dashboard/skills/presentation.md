# PPT 制作 Skill

## 概述
创建结构清晰、视觉专业的演示文稿。

## 演示文稿结构
1. **封面** — 标题、日期、演讲者
2. **目录** — 内容概览
3. **正文** — 核心内容（每页一个要点）
4. **总结** — 关键结论
5. **Q&A** — 问答环节

## 设计原则
- 简洁优先
- 视觉层次
- 一致性
- 适度动画

## 内容组织
- 每页一个核心观点
- 使用图表和图片
- 关键数据突出显示
- 避免大段文字

## 工具
- PowerPoint
- Google Slides
- Markdown → PDF
