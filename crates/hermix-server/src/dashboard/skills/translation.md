# 翻译 Skill

## 触发条件
当用户要求以下操作时使用此 Skill:
- "翻译" / "translate"
- "本地化" / "localize"
- "中译英" / "英译中"
- "翻译文档" / "translate document"

## 执行步骤
1. 确认源语言和目标语言
2. 理解原文语境和专业术语
3. 翻译并保持术语一致
4. 检查语法和流畅度

## 支持的语言
- 中文 <-> 英文
- 中文 <-> 日文
- 中文 <-> 韩文
- 英文 <-> 其他语言

## 翻译类型
### 文档翻译
- 技术文档、商务文档、法律文档

### 口语翻译
- 会议翻译、演讲翻译

### 本地化
- 软件界面、网站内容

## 输出格式
```
## 翻译结果

### [语言对]
[翻译内容]

### 术语表
- [术语 1]: [翻译 1]
- [术语 2]: [翻译 2]
```

## 翻译原则
- 准确传达原意（不遗漏、不添加）
- 符合目标语言习惯（地道表达）
- 保持专业术语一致（术语表）
- 注意文化差异（本地化）
