# 系统化调试 Skill

## 触发条件
当用户要求以下操作时使用此 Skill:
- "调试" / "debug" / "排错"
- "报错" / "出错" / "error"
- "程序异常" / "功能不正常"
- "定位问题" / "find the bug"

## 执行步骤
1. **复现**: 确认 bug 存在，找到稳定复现步骤
2. **隔离**: 缩小问题范围，二分法定位
3. **分析**: 理解预期 vs 实际行为，找出差异原因
4. **修复**: 实现最小修复，验证效果

## 4 阶段方法

### 1. 复现
- 确认 bug 存在
- 找到稳定复现步骤
- 记录复现条件（输入、环境、配置）

### 2. 隔离
- 缩小问题范围（文件、函数、行号）
- 二分法定位（注释一半代码、切换分支）
- 添加日志/断点

### 3. 分析
- 理解预期行为（读文档、看测试）
- 对比实际行为（输出、状态）
- 找出差异原因

### 4. 修复
- 实现最小修复（不引入新问题）
- 验证修复效果（运行测试）
- 防止回归（添加测试用例）

## 输出格式
```
## 调试报告
### 复现步骤
1. [步骤描述]

### 隔离结果
- 问题范围: [文件:行号]

### 根因分析
- 预期行为: [描述]
- 实际行为: [描述]
- 原因: [分析]

### 修复方案
[修复代码]
```
