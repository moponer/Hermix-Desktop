# 系统化调试 Skill

## 概述
系统化调试是高效解决 bug 的方法论，避免盲目尝试。

## 4 阶段方法
### 1. 复现
- 确认 bug 存在
- 找到稳定复现步骤
- 记录复现条件

### 2. 隔离
- 缩小问题范围
- 二分法定位
- 添加日志

### 3. 分析
- 理解预期行为
- 对比实际行为
- 找出差异原因

### 4. 修复
- 实现最小修复
- 验证修复效果
- 防止回归

## 工具
- 断点调试
- 日志分析
- 性能分析
- 内存分析
