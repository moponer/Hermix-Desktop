# 网文写作大师 Skill

## 概述

面向中文网文的写作辅助 skill。解决的是实际写作中的具体问题：

- 这个点子值不值得写成网文
- 这本书到底卖什么
- 前 10-20 章靠什么持续推进
- 开头怎么成交
- 中段怎么不散
- 章末怎么留后劲
- 怎么在全过程里避免 AI 味

## 三段式总流程

```
前置规划链 → 正文执行链 → 完稿收口链
```

### 1. 前置规划链
`concept_planning → opening / volume_outline`

决定"值不值得写、该怎么开"。

### 2. 正文执行链
`plot_logic → character_consistency → transition → dialogue → chapter_ending → anti_ai_voice`

解决具体的写作执行问题。优先级：因果和人物问题优先于场景和文风问题。

### 3. 完稿收口链
`consistency_review`

每章完稿后，对全文进行统一复查，六种一致性通过后才算完稿。

## 十大专项模块

### 1. concept_planning — 前置规划
- 把简介压成题材、消费点、hook、premise、故事引擎
- 判断长短和第一卷方向
- **硬要求**：先判断值不值得写，再写正文；先给卖点、冲突、故事引擎，再给大设定

### 2. opening — 开头
- 把卖点、异常局面和主角亮相落到开头成交区
- **硬要求**：前300-500字给抓手，前1500-3000字给卖点，前6000字让读者知道主角是谁、遇到什么、卖点是什么

### 3. volume_outline — 分卷章纲
- 黄金三章 → 分卷设计 → 卷末兑现点 → 前10-20章章纲
- 长篇网文默认必须写章纲，章纲必须包含每章的四要素

### 4. plot_logic — 剧情逻辑
- 修理"动机 → 触发 → 决策 → 后果 → 兑现"因果链
- 检查伏笔和兑现的平衡

### 5. character_consistency — 人物一致性
- 修理五类连续性：目标、情绪、关系、身体、声音

### 6. transition — 转场
- 时间跳切、空间切换、情绪承接、视角切换、章末接下章

### 7. dialogue — 对白
- 关系压力、人物声音、信息嵌入、对白刀口

### 8. chapter_ending — 章末
- 章末拉力、余韵、回钩、下章承接

### 9. anti_ai_voice — 反AI腔
- 清理空泛总结、套话氛围、说明书式对白、统一腔调
- **硬规则**：能用动作不用总结，能用对白不用解释，能写具体不写抽象

### 10. consistency_review — 一致性审查
- 统一复查六种一致性：剧情逻辑、人物目标、情绪与关系、身体与信息、场景与转场、章末承接
- 任意两项不稳不得直接交稿

## 核心方法

### 每章必须回答四件事
1. 主角这章想做什么
2. 谁或什么阻止他
3. 这章结束后局面变成什么
4. 为什么读者还要往下看

### 场景最小结构
每场戏至少要有：**目标 → 阻碍 → 变化**
没有变化的场景，默认删、并、压缩。

### 输出原则
- 默认只输出当前最需要的一层，不一次性堆满
- 先判断问题在前置规划、结构、单章执行还是完稿审查
- 如果问题已经明显收束到某一个写作环节，优先调用专项模块
- 先匹配例子或素材，再总结结构，再写新内容

## 模块调用总则

1. 先判断这是不是专项问题，而不是纯文风问题
2. 先读对应模块的说明，再按推荐顺序进入教程和例库
3. 先按模块的分层和分类法判断故障点
4. 去例库里选 2-4 个正例和 1-2 个反例
5. 先做局部修复计划，再写诊断、改写或正文
6. 如果问题跨多个模块，先修更底层、更硬的那一层

## 不要做的事

- 不要空谈"人物要立体""故事要有灵魂"
- 不要只给世界观，不给前几章方案
- 不要只给人设，不给冲突和事件
- 不要默认慢热
- 不要把模仿当成照抄
- 不要让对白全都一个腔调
- 不要输出像课程讲义一样的废话段落
- 不要把结构问题误修成文风问题

## 何时激活
- 用户有网文点子要评估值不值得写时
- 写到开头 / 中段散了 / 章末没劲时
- 人物前后矛盾、AI 味重、逻辑断链时

## 实践指南
1. 先判断问题在前置规划 / 结构 / 单章执行 / 完稿审查哪一层
2. 优先调用对应专项模块（如 plot_logic、anti_ai_voice）
3. 先匹配例库正例反例，再总结结构，再写新内容
4. 默认只输出当前最需要的一层，不一次堆满

## 注意事项
- 不要空谈"人物要立体""故事要有灵魂"
- 不要只给世界观不给前几章方案
- 不要把模仿当成照抄，不要让对白一个腔调
