# 投资分析 Skill

## 概述
提供股票和基金的投资分析框架，帮助做出理性的投资决策。

## 分析维度
### 基本面分析
- 财务报表分析
- 行业地位评估
- 管理层能力
- 成长性分析

### 技术分析
- K 线形态
- 技术指标（MACD、RSI、KDJ）
- 成交量分析
- 支撑阻力位

### 资产配置
- 分散投资
- 风险评估
- 投资组合优化

## 风险管理
- 止损策略
- 仓位控制
- 风险分散

## 何时激活
- 用户问"这支股票值不值得买 / 基金怎么选"
- 做资产配置、定投计划、风险评估时
- 看财报、技术图形、估值时想要方法论支撑

## 核心概念
- 基本面：公司内在价值（财报、行业、护城河）
- 技术面：价格与成交量的时空结构（趋势、支撑阻力）
- 资产配置：相关性分散风险，定期再平衡
- 风险预算：单笔仓位上限与止损线

## 实践指南
1. 先问目标与期限（短线 / 长线 / 养老）
2. 基本面定方向，技术面定买卖点
3. 用仓位和止损控制单笔风险，不孤注一掷
4. 输出时区分"事实"与"观点"

## 注意事项
- 不承诺收益、不推荐具体买卖点
- 过去表现不代表未来
- 杠杆与衍生品高风险，提示量力而行

## 集成
- 与 `finance-planning` 衔接：先有财务目标再谈投资
- 可与 `data-analysis` 配合做量化回测
