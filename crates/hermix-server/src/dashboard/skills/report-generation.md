# 报告生成 Skill

## 触发条件
当用户要求以下操作时使用此 Skill:
- "写报告" / "生成报告" / "report"
- "数据总结" / "数据分析"
- "周报" / "月报" / "年度总结"
- "项目总结" / "工作总结"

## 执行步骤
1. 确认报告类型和受众
2. 收集数据和信息
3. 按报告结构组织内容
4. 生成完整报告

## 报告类型
### 项目报告
- 项目进度报告、项目总结报告、风险评估报告

### 分析报告
- 数据分析报告、市场调研报告、竞品分析报告

### 工作报告
- 周报/月报、年度总结、专项报告

## 报告结构
1. **标题** — 明确报告主题
2. **摘要** — 关键发现概述（2-3 句）
3. **正文** — 详细分析和数据（分章节）
4. **结论** — 总结和建议
5. **附录** — 补充材料（可选）

## 输出格式
```
# [报告标题]

## 摘要
[关键发现概述]

## 1. [章节标题]
[分析内容]

## 2. [章节标题]
[分析内容]

## 结论
[总结和建议]
```

## 写作原则
- 数据驱动（用数据说话）
- 逻辑清晰（结构化表达）
- 结论明确（可执行的建议）
- 格式规范（标题层次、列表、表格）
