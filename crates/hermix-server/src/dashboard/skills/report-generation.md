# 报告生成 Skill

## 概述
根据用户需求生成结构清晰、内容专业的报告。

## 报告类型
### 项目报告
- 项目进度报告
- 项目总结报告
- 风险评估报告

### 分析报告
- 数据分析报告
- 市场调研报告
- 竞品分析报告

### 工作报告
- 周报/月报
- 年度总结
- 专项报告

## 报告结构
1. **标题** — 明确报告主题
2. **摘要** — 关键发现概述
3. **正文** — 详细分析和数据
4. **结论** — 总结和建议
5. **附录** — 补充材料

## 写作原则
- 数据驱动
- 逻辑清晰
- 结论明确
- 格式规范
