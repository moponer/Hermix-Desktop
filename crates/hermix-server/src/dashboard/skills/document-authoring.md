# 文档编制（画布流式）

制作文档类产物时走画布管线：你输出的 HTML 会在右侧文档画布里**随流实时
渲染**，用户边生成边看、可直接编辑。协议、几何、版面、落盘四件事按下面
执行，一条都不能省。

## 1. 画布协议（硬规则）

- 单条回复**至多一个** canvas 块。开启：

  ```
  <hermix-canvas page="slide16x9">
  ```

  `page` 只有两个合法值：**幻灯片/演示 → `slide16x9`**（横版 16:9）；
  **报告/周报/文档 → `a4`**（A4 竖版）。按用户的产物意图选，不要问、
  不要让用户"切换"。收口：`</hermix-canvas>`。收口之后**不要再写正文**
  （收口后的文本会被丢弃）。
- marker 之前可以有一两句引导语（如"我先列下大纲："），之后的增量全部
  归画布，聊天里不再重复内容。
- **每个块是一个自包含的页面**：
  - slide16x9：每页一个 `<slide>…</slide>`（块边界 = `</slide>`）；
  - a4：每页一个 `<section>…</section>`（块边界 = `</section>`）。
- 块是**纯追加**渲染的：上屏即冻结，"改第 3 页"= 输出一个全新的画布
  块（用户会看到新页面追加进来）。不要试图输出"补丁"。
- 表格类请求（"整理成 Excel"）：画布输出数据表 HTML
  （`<section><table>…</table></section>`），**数据必须完整、逐行给出**，
  禁止用"…其余类似"省略——用户要的是可导出的完整数据。

## 2. 版面规范

- **版面由设计 token 与一致的 CSS 承担，内容才由你写**。每个块顶部带
  一段 `<style>`（作用于块内）定义这套页面的字体、配色、间距——第一页
  定调，后续页**复用同一套 style**（复制第一页的 style 块），保证整份
  产物视觉一致。这是防"风格漂移"的关键：你只写内容结构，样式一次性
  定稿后不改。
- 字体栈：`"Segoe UI","Microsoft YaHei",system-ui,sans-serif`（画布已
  预设，块内不必重复声明 body 字体，除非刻意换标题字体）。
- slide16x9 页面 1280×720、内边距约 64×80px：**每页一个主张**，标题
  ≤ 28 字，正文要点 ≤ 6 条每条 ≤ 2 行；图表用内联 SVG 或纯 CSS 柱条
  （`div` + 宽高百分比），不用外部图片/JS 库（沙箱无网络）。
- a4 页面 794px 宽、内边距约 72×64px：标题层级 H1→H2→H3 严格递进，
  正文行高 1.7 左右，表格用完整 `<table>`（表头 `<th>` + 斑马纹可选）。
- 配色克制：一张产物至多 **1 个主色 + 1 个强调色** + 灰阶；禁止渐变
  横幅、单侧色条（side-tab 反模式）、弹跳动画。
- 中文排版：标点悬挂不强求，但段落间用 margin 分隔，不要用空行字符。

## 3. 落盘（产物持久化）

画布是易逝视图。**成稿后必须把完整 HTML 落盘**，让产物在会话结束后
仍在、可从预览栏打开：

- 用 `write_file` 把整份文档（含全部页面的自包含 HTML，外加 `<style>`
  的公共样式段）写到工作区，如 `报告-1013.html`。
- 落盘文件与画布内容一致：同一样式、同分页结构。落盘后告诉用户文件
  路径（会出现在产物列表）。
- 顺序：先画布（用户边看边等），写完同一回复内直接 write_file，不要
  等用户确认。

## 4. 质量门（与 impeccable 衔接）

- 画布 HTML 属于代码型产物：落盘后对文件跑
  `npx -y impeccable@4.1.0 detect <文件路径>`，退出码 0 才算干净
  （规则与豁免见 impeccable-design skill）。
- 用户要求"可编辑的 .pptx/.docx"时如实说明：当前交付形态是画布 HTML
  与打印 PDF（用户可在画布/文件上直接导出）；不要硬生成一个打开全歪
  的二进制 Office 文件冒充交付。

## 5. 反例（不要这样做）

- ❌ marker 后先写一大段解释再开始 HTML——解释进气泡没问题，但 HTML
  应紧跟 marker 之后立刻开始。
- ❌ 每页重新发明一套配色/字体——风格漂移，用户看到的就是"每页都不
  一样"。
- ❌ 幻灯片输出 `<section>` 或文档输出 `<slide>`——块边界错了页面
  切分就错。
- ❌ 数据表只给示例行然后写"其余以此类推"——画布不是示意，是产物。
- ❌ 收口后继续输出内容（会被丢弃）或输出第二个 canvas（协议禁止）。
