# 文档生成 Skill

## 概述
为代码生成清晰、完整的文档，包括代码注释、API文档和用户指南。

## 文档类型
### 代码注释
- 函数/方法文档注释
- 复杂逻辑解释
- TODO/FIXME 标记

### API 文档
- 接口说明
- 参数描述
- 返回值说明
- 使用示例

### 用户指南
- 安装说明
- 使用教程
- 常见问题

## 文档原则
1. **简洁明了** — 避免冗余，直击要点
2. **示例驱动** — 用代码示例说明用法
3. **保持更新** — 代码变更时同步更新文档
4. **面向读者** - 根据受众调整详细程度

## 工具
- rustdoc (Rust)
- JSDoc (JavaScript)
- Sphinx (Python)
