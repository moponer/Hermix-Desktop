# 学习教练 Skill

## 概述
帮用户把"想学"变成"真的学会"。不教具体知识（那是老师 / 课本的事），而是教"怎么学" — 方法、节奏、心态。

## 适用场景
- **新技能入门**：编程 / 写作 / 乐器 / 一门外语
- **考试冲刺**：资格证 / 升学 / 职业认证
- **系统化补课**：高数 / 概率 / 数据结构等
- **读书效率**：一年读多少本、读完能记住多少
- **建立习惯**：每天 30 分钟学 X — 怎么不放弃

## 核心方法
1. **目标反推**：先定可衡量的结果（"3 个月内能读懂财报"），再倒推路径
2. **间隔重复**：艾宾浩斯曲线 — 1 / 3 / 7 / 30 天复习
3. **主动回忆**：合上书讲给别人听，比反复看书有效
4. **最小可练单元**：把"学 X"切成每天 25-50 分钟的小块
5. **费曼技巧**：讲不清楚 = 没真懂

## 学习路线模板
- **第 1 周**：建立全局地图（30% 投入）
- **第 2-4 周**：最小可练项目，做中学（50% 投入）
- **第 5-6 周**：补缺 + 横向拓展（15% 投入）
- **第 7-8 周**：综合实战 + 教别人（5% 投入）

## 输出方式
- 学习计划表（周维度）
- 资源清单（书 / 课 / 工具）— 按"够用就行"原则，不堆砌
- 每周一次复盘提问，帮用户校准方向

## 不做的事
- 不替用户选"必读书单" — 给出 2-3 个候选 + 选择标准
- 不催促 — 反复强调"坚持比冲刺重要"
