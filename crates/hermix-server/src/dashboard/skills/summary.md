# 内容摘要 Skill

## 概述
从长文档、文章或对话中提取核心内容，生成简洁的摘要。

## 摘要类型
### 文档摘要
- 技术文档摘要
- 论文摘要
- 报告摘要

### 会议摘要
- 讨论要点
- 决策结果
- 行动项

### 对话摘要
- 关键信息
- 待办事项
- 后续计划

## 摘要原则
- 保留核心信息
- 简洁明了
- 结构清晰
- 重点突出

## 摘要格式
1. **主题** — 文档/对话的主题
2. **要点** — 3-5 个核心要点
3. **结论** — 关键结论或决定
4. **行动项** — 待办事项（如有）
