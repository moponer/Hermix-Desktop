# 数据库设计 Skill

## 概述
数据库设计是应用开发的基础，影响性能、可维护性和扩展性。

## 设计步骤
1. 需求分析：确定数据实体和关系
2. 概念设计：ER 图
3. 逻辑设计：表结构设计
4. 物理设计：索引和分区

## 关系型数据库
- MySQL / PostgreSQL
- 事务支持
- ACID 特性
- 适合结构化数据

## NoSQL 数据库
- MongoDB：文档型
- Redis：键值对
- Cassandra：列式存储
- 适合非结构化数据

## 优化
- 索引优化
- 查询优化
- 缓存策略
