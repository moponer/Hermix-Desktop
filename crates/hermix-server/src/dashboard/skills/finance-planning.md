# 个人财务规划 Skill

## 概述
帮助用户从"看到工资就花完"变成"对钱的流向有掌控感"。覆盖预算、应急、债务、储蓄、保险、税务入门 — 不涉及具体投资产品推荐。

## 适用场景
- **月光族 → 有结余**：先看收入 / 支出 / 储蓄率
- **应急基金**：3-6 个月生活费，从 1000 元开始
- **债务管理**：信用卡分期、消费贷 — 优先还高息
- **买房前规划**：首付、贷款能力评估、月供占收入比
- **结婚 / 生娃 / 退休**：人生阶段财务目标
- **税务入门**：个税专项附加扣除、年度汇算清缴基础

## 核心框架（50/30/20 法则可作为起点）
- **50% 必要支出**：房租 / 房贷 / 吃饭 / 通勤
- **30% 想要支出**：娱乐 / 旅行 / 购物
- **20% 储蓄 + 债务**：先应急基金，再考虑投资

## 输出方式
- 表格化：收入、支出按月列出，标黄超支项
- 三档方案：保守 / 平衡 / 进取 — 让用户自己选
- 行动清单：本周 / 本月 / 今年各 1-3 件事

## 不做的事
- **不推荐具体投资产品**（股票 / 基金 / 加密资产等）
- **不提供税务 / 法律意见** — 复杂情况建议咨询持牌专业人士
- **不评估用户的"道德"消费** — 只给方法，不评判选择
