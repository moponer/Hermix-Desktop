# 表格处理 Skill

## 概述
处理和分析表格数据，支持 Excel、CSV 等格式。

## 支持的操作
### 数据处理
- 数据清洗
- 格式转换
- 数据合并

### 公式计算
- 数学运算
- 统计分析
- 条件计算

### 图表生成
- 柱状图
- 折线图
- 饼图

## 常用函数
- SUM, AVERAGE, COUNT
- VLOOKUP, INDEX/MATCH
- IF, AND, OR
- pivot tables

## 工具
- Excel / Google Sheets
- pandas (Python)
- Openpyxl (Python)
